Advanced Database Modeling, Normalization, and Data Migration Using SQLite For Movies Dataset

This project explored advanced data modeling concepts with a strong focus on designing clean, reliable, and efficient database structures. Through lessons on referential integrity, normalization, naming conventions, data types, and data storage principles, the module emphasized why proper database design is essential for performance, accuracy, and long-term maintainability. We worked hands-on with the NEU student database and DB Browser for SQLite, practicing SQL syntax, creating data structures, cleansing external datasets, and understanding how anomalies and poor design choices affect real-world systems. The curriculum highlighted both theory and process, teaching how to move from conceptual modeling to high-quality relational structures that stakeholders and downstream users can trust.

Building on these foundations, the project guided us through importing, cleaning, and validating data, identifying issues such as type mismatches and inconsistent formatting that commonly arise in analytics and informatics workflows. By the end, we gained practical skills applicable to enterprise databases: interpreting complex ERDs, designing normalized schemas, performing successful data migrations, and creating small proof-of-concept databases to support business decision-making. The final deliverable involved populating tables from a structured movies dataset using SQLite, demonstrating our ability to apply database theory to a functional, real-world solution.
